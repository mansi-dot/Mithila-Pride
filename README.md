# 🌸 Mithila Pride

An elegant Django-based E-Commerce Website for Handmade Mithila Paintings.

---

## 📌 Features

- 👤 User Authentication (Login & Signup)
- 🛍️ Product Listing
- ❤️ Wishlist
- 🛒 Shopping Cart
- 💳 Razorpay Payment Integration
- 📦 Order Management
- ⭐ Product Reviews
- 📊 Admin Dashboard & Analytics
- 📂 Category Management
- 📞 Contact Form
- 📄 Invoice Download

---

## 🛠️ Tech Stack

- Python
- Django
- HTML5
- CSS3
- JavaScript
- SQLite
- Razorpay
- Git & GitHub

---

## 🚀 Installation

```bash
git clone https://github.com/mansi-dot/Mithila-Pride.git

cd Mithila-Pride

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
