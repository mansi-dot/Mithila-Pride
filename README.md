## 📖 About the Project

**Mithila Pride** is a Django-based e-commerce website where customers can explore and purchase handmade Mithila paintings.

The project includes user authentication, shopping cart, wishlist, order management, Razorpay payment integration, product reviews, analytics dashboard, and an admin panel.

---

# ✨ Features

- 👤 User Registration & Login
- 🛍️ Product Listing
- 📂 Product Categories

# 🚀 Installation

```bash
git clone https://github.com/mansi-dot/Mithila-Pride.git

cd Mithila-Pride

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
